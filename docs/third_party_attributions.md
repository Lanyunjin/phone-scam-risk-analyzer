# Third-party attributions

The project references the following third-party components. Each remains under
its own license, copyright, service terms, and attribution requirements. The
project's All Rights Reserved notice does not replace or extend to third-party
materials.

- **Azure Cognitive Services Speech SDK** — speech recognition and conversation
  transcription client. Use is subject to Microsoft's applicable SDK license
  and Azure service terms.
- **TensorFlow/Keras** — neural-network architecture, training, and inference.
- **Gensim** — optional downloader/loader for pretrained embeddings.
- **GloVe** — `glove-wiki-gigaword-300` pretrained vectors. The vectors are not
  redistributed here. Users must review the source dataset, Stanford GloVe, and
  Gensim data terms before downloading or using them.
- **scikit-learn** — grouped splitting and aggregate evaluation metrics.
- **NumPy** — numerical arrays and embedding-matrix construction.
- **pandas** — tabular schema validation and caller-supplied CSV loading.

Before redistribution or deployment, verify the current license and service
terms from each official source. This document is an attribution checklist, not
legal advice.
